# 초기 탐색 기록 (10/12)

프로젝트 초기에 AI 도구로 데이터 적재 확인, 활동 집계, 품목 분류를 빠르게 훑어본 기록입니다.

이후 같은 단계를 `my_sql/`과 `notes/my_*`에서 직접 다시 수행했고, 두 결과를 비교해 처리 규칙 하나를 바꿨습니다(`notes/my_02_quality_check.md` 5절).

- 초기 규칙: 2018년 이전 날짜가 있는 품목 193개를 통째로 제외
- 확인: 해당 품목을 열어 보니 송장 날짜만 이상하고, 발주부터 지급까지의 기록은 정상
- 변경: 품목은 남기고 그 날짜만 소요일 계산에서 제외

이 폴더의 파일은 비교 근거로 남기기 위해 당시 상태 그대로 두었습니다. 최종 분석과 수치는 상위 폴더의 README를 기준으로 봐 주세요. `src/run_sql.py`는 원래 위치 기준으로 작성되어 있어 이 폴더에서는 그대로 실행되지 않습니다.
