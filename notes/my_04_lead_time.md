## 해석 (리드)
1. 가장 오래 걸리는 구간은 C "송장 접수 → 지급", 중앙값 43일. 전체 77.1일의 약 56% (중앙값은 더해지지 않아 대략치)
2. C의 P90은 97.9일 → 지급까지 오래 걸리는 10%는 송장 접수 후 약 98일 이상
3. B 음수 8.7%는 오류가 아니라 이 데이터 유형(3-way match, invoice before GR)의 정상 흐름: 송장이 입고보다 먼저 접수됨

결론 한 줄: 물건은 9일 안팎이면 들어오고 송장도 곧 접수되지만, 송장 접수 후 지급까지가 가장 길다. 병목은 지급 단계.

## C 구간 음수 9건 (리드, 10/23)
- 구간별 음수: A 0 / B 14,963 / C 9 / 전체 0
- C 음수 = 지급 시각이 송장 접수보다 이름. 9건 모두 발주 번호 다름, 18분짜리 1건, 나머지 8건 5~210일
- 예시 4507016022_00020: 업체 송장 발행 3/31 → 입고 4/4 → 지급 5/24 → 송장 접수 12/20, 활동마다 1번씩 → 첫 시각 규칙 때문은 아님
- 원인 가설: 선급금, 송장 접수 지연 입력 → 이 데이터로는 확인 불가 [미확인]
- 영향: C 중앙값 42.99일, 9건 빼도 42.99일
- 처리: C 구간 계산에서 제외. 이유: 중앙값 영향이 없어 제외해도 무방

### 리드가 먼저 정한 것
- 질문: C 구간(송장 접수→지급)이 오래 걸린 품목은 어떤 공급사에 몰려 있나? 그다음 어떤 지출 영역에 몰려 있나?
- 지연 기준: C 구간 P90(97.9일) 초과
- 예상: 감이 안 옴 → 결과 보고 판단
- C 음수 9건은 제외 (c >= 0)

### 결과 1: 공급사별 (리드 작성 쿼리)
- 전체 지연 품목(C > 97.9일): 17,165건 = 172,241건의 10.0%
- 지연 건수 비중: 1위 vendorID_0136 7,694건(44.8%), 상위 4곳 86.7%, 상위 10곳 92.9%
- 지연 비율(지연 품목 ÷ 그 업체 전체 품목): 0136 73.2%, 0120 33.6%, 0103 58.5%, 0182 30.0%, 0278 55.4% / 7~10위는 3~11%
- 0136과 0120은 전체 품목이 거의 같은데(10,518 vs 10,411) 지연 비율은 73.2% vs 33.6% → 거래가 많다고 지연이 많은 건 아님
- 판단 기준(리드): 지연 품목 누적 90%를 덮는 업체(상위 10곳, 92.9%) 중 지연 비율 30% 이상 = 우선 관리 대상
  - 30% 이유: 전체 평균 지연 비율 10%의 3배
- 우선 관리 대상: 0136(73.2%), 0103(58.5%), 0278(55.4%), 0120(33.6%), 0182(30.0%) → 5곳, 지연 품목 15,400건 = 전체 지연의 89.7%

### 검증: 0136 지연 품목 직접 보기 (리드 작성 쿼리)
- 예시 4508044951_00020 (C 119.9일): 송장 접수 8/9 → 지급 보류 해제 8/10 → 4개월 활동 없음 → 지급 12/7. 쿼리 결과와 일치
- 이 품목은 보류 해제가 하루 만에 끝나고, 해제 후 지급까지 기다린 시간이 지연
- 0136 보류 해제(Remove Payment Block) 기록 비율: 지연 품목 4,455/7,694 = 57.9% / 지연 아닌 품목 1,201/2,824 = 42.5%
- 지급 보류 기록: Set Payment Block 52건 vs Remove Payment Block 54,458건 → 보류를 거는 기록은 거의 없음
- 한계: 보류는 "해제 기록"으로만 간접 확인 가능. 결제 조건 컬럼이 없어 지급 조건 때문인지는 확인 불가 [미확인]
- 해석(리드): 지급 단계(절차) 문제라면 구매한 회사 쪽, 아니라면 공급사(0136) 쪽 문제. 0136은 지연 비율이 평균의 7배이고, 보류만으로는 지연이 설명되지 않음. 둘 중 어느 쪽인지는 결제 조건·지급 일정 정보가 있어야 가릴 수 있음 [미확인]

## ④ 결론 (리드, 10/26)
1. 송장 접수 → 지급(C 구간)이 병목. 중앙값 43일, P90 97.9일로 가장 길다.
2. C 구간 지연(97.9일 초과) 17,165건의 93.4%가 Packaging 영역이고, 그중 5개 공급사가 Packaging 지연의 95.7%, 전체 지연의 89.3%를 차지한다.
3. 거래가 많아서가 아니다. 0136과 0120은 품목 수가 비슷하지만 지연 비율은 73.2%와 33.6%로 다르다.
4. 구매 회사별 차이, 결제 조건, 보류가 걸린 시점은 확인하지 못했다. 지급까지 끝난 172,241품목만 본 결과다(before GR 방식 데이터만). 지급 없는 44,594품목은 17.4%가 삭제·취소, 75.5%가 데이터 끝(2019-01) 직전에 멈춘 진행 중 건이며, 그중 57.8%는 송장까지 받고 지급만 없는 상태라 C 구간 병목과 같은 방향이다. 우선 관리 5곳 중 4곳이 미지급 상위에도 있다(미지급의 23.8%).
5. 구매 회사 지급 담당은 Packaging 5개 공급사 건부터 결제 조건과 지급 일정을 확인한다.

### 반영 전 확인 후보 (리드가 할지 결정)
